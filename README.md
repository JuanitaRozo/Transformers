# Transformers aplicados a Series de Tiempo

## Descripción
Este proyecto implementa y compara dos modelos de Deep Learning para la predicción de series temporales: un mecanismo de atención y una arquitectura Transformer básica.

## Contenido
- `Mecanismo de atención aplicado a series de tiempo.ipynb`: implementación del mecanismo de atención.
- `Implementación de un Transformer básico.ipynb`: implementación del modelo Transformer.

## Herramientas utilizadas
- Python
- Google Colab
- TensorFlow y Keras
- NumPy, Pandas y Matplotlib
- Scikit-learn

## Objetivo
Analizar el funcionamiento de los mecanismos de atención y Transformers, evaluar sus predicciones y comparar sus resultados mediante métricas de error.
